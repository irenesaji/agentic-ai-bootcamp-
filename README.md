# Agentic AI Bootcamp

Welcome to my **Agentic AI Bootcamp** repository.

This repository contains my learning exercises, assignments, projects, and experiments related to **Artificial Intelligence and Agentic AI**.

## Objectives

* Learn the fundamentals of Artificial Intelligence
* Understand Generative AI and Large Language Models (LLMs)
* Learn how AI agents work
* Build practical Agentic AI applications
* Explore AI tools, APIs, and frameworks
* Apply software development concepts to AI projects

## 📁 Project Structure

```text
agentic-ai-bootcamp/
│
├── src/

│
├── README.md

```

### `src/`

Contains the main source code for the projects and exercises.

### `main.py`

The starting Python program for the project.

### `requirements.txt`

Contains the Python dependencies required by the project.

### `.gitignore`

Specifies files and folders that should not be tracked by Git.
